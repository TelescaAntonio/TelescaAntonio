# Hi, I'm Antonio Telesca

**AI Systems Engineer | Cybersecurity Researcher | Edge Computing Enthusiast**

I design and build autonomous AI agents that run on unconventional hardware -- from $200 NAS devices to rooted smartphones running Kali Linux. My work sits at the intersection of artificial intelligence, cybersecurity, and edge computing, with a focus on making powerful AI systems accessible on minimal infrastructure.

---

## What I Do

I specialize in deploying AI agents on resource-constrained devices, creating systems that operate autonomously through natural language interfaces. My approach combines open-source AI frameworks with professional-grade security tools to build solutions that would traditionally require enterprise hardware and budgets.

My current research explores three frontiers: using mobile devices as portable AI-powered penetration testing platforms, transforming consumer NAS hardware into self-managing intelligent home servers, and building intelligent system control agents for Linux environments.

## Research Interests

My research focuses on three emerging areas. The first is **Agentic Edge AI** -- deploying autonomous AI agents on edge devices rather than cloud infrastructure. The second is **Natural Language Cybersecurity** -- using LLMs to democratize penetration testing tools through conversational interfaces. The third is **Autonomous Home Infrastructure** -- creating self-managing home servers that require zero technical knowledge for daily operation.

I believe the next wave of AI innovation will not come from bigger models in bigger data centers, but from smaller, smarter agents running on the devices we already own.

---

## Philosophy

I build systems that prove expensive infrastructure is not required for powerful AI. Every project I publish is open-source, documented for reproducibility, and designed to run on hardware anyone can afford. If an AI agent needs a $10,000 GPU cluster to be useful, it is not useful enough.
